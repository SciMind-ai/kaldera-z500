# Kaldera Z500 microsite
Static site (HTML/CSS/JS). Fictional brand, for demo use.
Files: index.html, about.html, privacy.html, css/style.css, js/main.js, js/ads.js, ads.txt, robots.txt.
GitHub Pages: repo Settings > Pages > Deploy from branch > main > / (root).
Ads: paste the ad code exactly as Adsterra gives it (do not edit it) inside the div with id="ad-banner" in index.html, about.html and privacy.html. js/ads.js is optional and can be left empty.
ads.txt: use only if your Adsterra dashboard gives you a line for it.
